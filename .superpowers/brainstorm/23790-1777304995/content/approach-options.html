RAG 产品文档助手：方案选择

目标：边界能力划分 + 适度推断 + 必须可追溯引用 + 本地文档

A. 最简 Python 版（推荐）

FastAPI + Chroma + LangChain + OpenAI Embedding + GPT

优点

  • 教程最多，小白最容易跑通
  • 组件清晰，便于后续替换
  • 1-2 周可做出可演示版本

缺点

  • 依赖较多，需要学一点框架概念
  • 链路调试需要看日志

B. LlamaIndex 一体化版

LlamaIndex + FastAPI + 本地向量库

优点

  • 封装更高，开发更快
  • RAG 组件开箱即用

缺点

  • 黑盒感更强，不利于打基础
  • 遇到定制需求时学习成本上升

C. 无框架手写版

FastAPI + 手写检索/重排/提示词链路

优点

  • 最透明，理解最深入
  • 没有框架锁定

缺点

  • 实现周期更长
  • 小白初期更容易卡住

建议：先选 A 跑通，再逐步替换模块，既能快速上线，也能学到底层逻辑。
