# 数据集页面逻辑与交互功能说明

页面文件：`evaluation_update_for_c4d/dataset_management.html`

## 1. 文档目标

本文档仅描述数据集页面的页面结构、逻辑路径与交互功能，不包含通用设计规则（通用规则见 `evaluation-platform-general-design-rules.md`）。

---

## 2. 页面结构说明

### 2.1 第一层：数据集列表页

结构：
1. 左侧固定导航（提示词管理 / 数据集 / 评估记录等）。
2. 顶部栏显示当前页面标题“数据集”（单一标题源）。
3. 工具栏：左侧搜索框，右侧新增数据集按钮（带下拉菜单）。
4. 主体为数据集表格，底部分页信息与翻页按钮。

列表字段：
1. ID（左冻结）
2. 数据集名称（左冻结）
3. 环境（tag）
4. 创建类型（tag）
5. 总数（S/T）
6. 描述
7. 创建时间
8. 操作（右冻结：详情、删除）

### 2.2 第二层：数据集详情页

结构：
1. 顶部面包屑：`数据集 / 数据集名称`，支持返回列表。
2. 汇总 bar：Session 数、Trace 数、环境、类型。
3. 搜索框：支持按 session id / trace id 过滤。
4. Trace 明细表格。
5. 右侧详情抽屉（高层级覆盖），展示单条 trace 详细信息。

---

## 3. 列表页交互功能

1. 搜索：按数据集名称即时过滤。
2. 行点击：点击任意行任意位置进入详情页。
3. 名称样式：名称不再作为单独链接，避免重复点击语义。
4. 操作列：
   - 详情：进入该数据集详情
   - 删除：从当前列表中移除该数据集（局部更新）
5. 冻结列：
   - 左侧冻结 `ID`、`数据集名称`
   - 右侧冻结 `操作`
   - 横向滚动时冻结列遮盖后方内容
6. 表格显示规则：
   - 全字段单行
   - 超出截断
   - hover 显示完整值

---

## 4. 新增数据集交互功能

入口：
1. 点击“新增数据集”弹出下拉菜单。
2. 当前保留两种创建方式：
   - 按 session 创建
   - 按 trace 创建

### 4.1 按 session 创建（弹窗）

1. 字段：
   - 数据集名称（必填）
   - Langfuse 环境（必填）
   - Session ID（必填，支持换行/逗号批量输入）
   - 描述（选填）
2. 文件导入（.xlsx / .csv）：
   - 点击上传后，上传区隐藏
   - 显示已上传文件 + sheet + 字段列 + 同步按钮
   - “同步导入session”将列数据写入 Session ID 输入框
   - 点击删除上传文件（×）后恢复上传初始态
3. 提交：
   - 创建成功后新数据集插入列表第一行
   - 不刷新整页

### 4.2 按 trace 创建（弹窗）

1. 顶部公共字段：
   - 数据集名称（必填）
   - Langfuse 环境（必填）
2. 三个互斥 tab：
   - 粘贴 JSON
   - 按 trace id 导入（含文件导入）
   - 按 session 查 trace
3. 按 session 查 trace：
   - 左侧输入 session ID 后查询
   - 右侧预览区支持勾选、全选/取消全选
   - 底部候选区展示已选项，支持单项移除与清空
   - 预览区与候选区双向同步
4. 提交：
   - 创建后插入列表第一行
   - 类型为 trace，总数列按 trace 逻辑显示

---

## 5. 详情页与抽屉交互功能

1. Trace 列表行点击打开右侧抽屉。
2. 抽屉展示三组信息：
   - 身份信息（id/session id/trace id）
   - 内容信息（用户输入/模型输出/metadata）
   - 创建时间
3. 抽屉支持 Prev / Next 切换记录。
4. 切换时列表选中行同步更新。
5. 抽屉关闭后取消行高亮。
6. 抽屉宽度已扩大，层级高于列表，避免被表头/正文覆盖。

---

## 6. 当前实现边界

1. 当前页面为高保真前端原型（mock 数据驱动）。
2. 文件导入、JSON 解析、session 查询等为演示逻辑，不直接连真实后端。
3. 行为设计可直接作为后续工程化实现的交互基线。
